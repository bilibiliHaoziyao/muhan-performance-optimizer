# 慕寒性能优化

一款面向非专业用户的 Android 手机性能监控与运存优化工具，卡片化实时展示设备核心状态，并提供智能运存清理。

> 您的隐私，我们的责任：本软件不联网、不收集隐私、不放恶意代码。

## 功能特性

### 优化（首页）
- 实时显示运存占用率、已用/总量、可用空间与占用趋势曲线
- 自动清理运存：运存占用达到阈值（50%–95% 可调，默认 80%）时自动清理后台进程，每 3 分钟检查一次
- 清理白名单：默认保护 QQ、微信，可自由添加/移除应用
- 一键立即清理 + 今日清理次数统计
- 后台监控服务常驻运行，忽略电池优化申请，功耗极低

### 概览
- 电量 / CPU / 内存 / 温度 / 刷新率 / 网络实时卡片
- CPU、电量、功率实时曲线，同步显示实时数字与单位

### SoC
- 芯片型号、CPU 架构与各核心实时使用率
- 分核心详情：每核心利用率、频率 + 实时曲线

### 系统
- Android 版本、API、系统版本、开机时长、内核等

### 电池
- 电量、电压、电流、温度、功率、健康状态

### 屏幕
- 分辨率、刷新率、亮度等

### 存储
- RAM / 存储分区使用情况

### 卫星
- GNSS 卫星连接（北斗 / GPS / GLONASS / Galileo 分类统计）
- 纬度、经度、高度、海平面高度、速度
- 卫星通信支持检测

## 构建

需要 JDK 17 与 Android SDK（platform 35、build-tools 34+）。

```bash
# 调试包（如需正式签名请修改 debug 构建配置）
gradle :app:assembleDebug

# 发布包（使用 app/release.keystore 签名）
gradle :app:assembleRelease
```

APK 输出至 `app/build/outputs/apk/`。
